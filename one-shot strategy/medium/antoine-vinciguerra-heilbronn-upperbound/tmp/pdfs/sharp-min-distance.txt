                                                  THE SHARP EXPONENT FOR THE MINIMAL DISTANCE PROBLEM

                                                                                         COSMIN POHOATA


                                                   Abstract. We show that for every fixed ε > 0, there exist arbitrarily large families of
                                                   point–line pairs ( x1 , ℓ1 ), . . . , ( xn , ℓn ) in [0, 1]2 , with xi ∈ ℓi for all i, and such that
                                                                                  dist( xi , ℓ j ) ≥ n−2/3−ε     ( i ̸ = j ).
                                                   Combined with a previous result of Cohen, the author, and Zakharov, this solves the
                                                   minimal distance problem.
                                                      The same construction also comes with an unexpected finite field consequence: for every
                                                   ε > 0, there exists a set of primes q of positive relative density for which F2q contains an
                                                   induced point-line matching of size ≳ε q3/2−ε . This disproves a conjecture of Hunter, the
                                                   author, Verstraëte and Zhang.

   The same construction also comes with an unexpected finite field consequence. For a
prime power q, let IM(2, q) denote the largest n for which there exist points p1 , . . . , pn ∈ F2q
and affine lines ℓ1 , . . . , ℓn ⊂ F2q such that pi ∈ ℓ j if and only if i = j. As discussed in
[6, 7, 12], this is a natural finite-field model for the minimal distance problem: avoidance
of off-diagonal incidences over Fq plays the role of quantitative point–line separation
over R. A simple Cauchy-Schwarz incidence estimate gives IM(2, q) ≤ q3/2 + q, for every
prime power q. This may be viewed as the finite-field precursor of (2).
   When q is a square, the Hermitian unital gives an induced matching of size q3/2 ,
showing that this estimate is sharp up, to lower-order terms. See for example [12] for a
more elaborate discussion. For fields of prime order q, the situation is significantly more
mysterious. In [12, Theorem 1.2], Hunter–Pohoata–Verstraëte–Zhang used (5) to prove
that IM(2, q) ≳ q1.2334... holds for all primes q, thereby establishing a separation between
this problem and the closely related problem of determining the size of the largest clique
in the Paley graph of prime order q. Furthermore, in [12, Conjecture 10.2], the authors also
subsequently conjectured that IM(2, q) ≤ q3/2−c must hold for some absolute constant
c > 0, for all sufficiently large primes q.
   Using the construction behind Theorem 1.1, we can show that this conjecture is false, as
originally stated.

Overview. The proof of Theorem 1.1 will build upon the ideas from [12]. Roughly
speaking, the driving force behind the relation (4) is a very simple polynomial identity: if
Q( x, y) = 2x − y2 ∈ Z[ x, y], then
          Q ( x, y) + t(y, 1) = Q x + ty, y + t = Q( x, y) − t2 , for every t ∈ Z.

This has the following crucial consequence.     If A ⊂ [ N ] is a set of integers without perfect
square differences, and we let P = ( x, y) ∈ R2 : Q( x, y) ∈ A , then the “integer line"

ℓ x,y = {( x, y) + t(y, 1), t ∈ Z} can only intersect P at the point ( x, y) itself. After further
reflection, this allows one to convert a square-difference-free set A ⊂ [ N ] of Q-values
into an induced point–line matching in the Euclidean plane. A direct computation can
then subsequently show that such an induced point-line matching is in fact a point-line

incidence configuration with strong Euclidean separation (in the sense of (1)). Over
the integers, the quality of this separation will constrained by the Furstenberg–Sárkőzy
problem and by the density of the Ruzsa sets A ⊂ [ N ].
   For s( N ) constructions, it is well-known that the natural endpoint of the Ruzsa digit
method is β = 3/4 − o (1), which (4) would readily convert into the exponent γ = 4/5 +
o (1) for the minimal distance problem. In order to use (5) to show that s( N ) ≳ N 3/4−o(1) ,
one would however need to find, for squarefree moduli m, modular square-difference-free
sets of size m1/2−o(1) . At a single prime this becomes a large independent-set problem
in the Paley graph and square-root-size examples are not expected. Composite moduli
could in principle allow for more elaborate entangled constructions, but in practice the
best known exponent remains ≈ 0.733411797 (and achieving the 3/4 − o (1) limit for s( N )
might not even be possible with this method to begin with).
   The proof of Theorem 1.1 bypasses this barrier and the Ruzsa limit altogether, by
performing the same construction (from scratch) in a high degree totally real number
field instead. A key idea will be to replace the Ruzsa set by the trace-zero slice of
its ring of integers. The positivity of the quadratic form TrK/Q (z2 ) rules out nonzero
square differences in this slice, while the field norm converts algebraic nonvanishing into
quantitative Euclidean separation after one real embedding.
Remark 1.4. Curiously, the high degree number fields enter the proof of Theorem 1.1 in a
very different manner than how they do in the recent constructions for the unit distance
problem [1, 13], the sum-product problem over the reals [5], and the Elekes-Rónyai
problem [20]. In all these other arguments, a local gain is (vertically) amplified across
many residue-field, unit, or archimedean coordinates, and one needs arithmetic control,
e.g. bounded root discriminant and/or split primes, to keep the ambient lattice from
overwhelming that gain. See for example [20, 3, 24] and the references therein for more
systematic discussions. Here the field is fixed before the box grows, and no sophisticated
tower, split-prime input, or uniform regulator estimate is needed. The trace equation
removes only one global dimension, and the degree increase will be used solely to dilute
the effect of this fixed codimension. Thus, for example, if ζ p = e2πi/p denotes a primitive
pth root of unity, it suffices to take K = Q(ζ p + ζ − 1

                                  6. Concluding remarks
  Many other interesting problems remain open. For example, we do not believe that
the sharpness of the 2/3 exponent for the minimal distance problem means also that the
Cohen–Pohoata–Zakharov upper bound of ∆H (n) ≤ n−7/6+o(1) should be definitive for
the Heilbronn triangle problem. In particular, note that the proof of
                                  ∆H (n) ≲ n−1/2 ∆PL (⌊cn⌋),
discussed in Section 1, discards a substantial amount of geometry. In this spirit, we would
like to take the opportunity to formally state the following conjecture:
Conjecture 6.1. There exists an absolute constant c > 0 such that
                                       ∆H (n) ≲ n−7/6−c .
   Analogously, we also believe that s( N ) ≤ N 1−c should hold for the Furstenberg–Sárkőzy
problem. This belief was already recorded in several other places, see e.g. [10]. In light
of the proof of Theorem 1.1, it seems also natural to study the following number field
generalization. For a fixed totally real field K of degree d ≥ 1, let
                         n                                                       o
          sK ( X ) := max | A| : A ⊂ BK ( X ), ( A − A) ∩ {z2 : 0 ̸= z ∈ OK } = ∅ .
The case K = Q is exactly the classical Furstenberg–Sárkőzy problem. Indeed, in this
case we have that OK = Z and BQ ( X ) = {−⌊ X ⌋, . . . , ⌊ X ⌋}. Therefore, after appropriately
translating, it follows that sQ ( X ) = s(2⌊ X ⌋ + 1). See also the closely related version from
[18] for general number fields.
   For a totally real field K of degree d ≥ 2, the trace-zero lattice used in our proof of
Theorem 1.1 gives sK ( X ) ≳K X d−1 . Conversely, Z · 1 is a primitive direct summand of
the additive group OK , so one may partition BK ( X ) into OK ( X d−1 ) fibers parallel to this
copy of Z. The intersection of A with each such fiber, after translation, is an ordinary
square-difference-free set contained in an interval of length OK ( X ). The result of [10]
therefore implies
                           X d−1 ≲K sK ( X ) ≲K X d exp −c log X
                                                             p        

for an absolute constant c > 0. It would be interesting to narrow this gap for sufficiently
large d.
   Finally, in the spirit of [12], it is also natural to ask about the higher-dimensional
analogues of Theorems 1.1 and 1.3, together with their potential applications to Nikodym
sets and minimal blocking sets. We intend to address these in a separate work.
