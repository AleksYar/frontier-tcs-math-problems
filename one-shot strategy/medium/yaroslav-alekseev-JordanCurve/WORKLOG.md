Hence both walks are coordinate-monotone. For each vertical cut `k|k+1`, binary search in time locates the unique horizontal crossing edge of either path while retaining two anchors; long-range monotonicity makes every adversarial midpoint response consistent with the search predicate or immediately losing. If the red and blue crossing heights coincide, disjointness is violated. Binary search over columns retains witnesses to both inequalities and finds adjacent cuts where the order flips. In the intervening column, the red upward interval and blue downward interval overlap; a final time binary search forces an equal vertex. Only a constant number of full `2d`-bit blocks are retained, so the Boolean width is `O(d)` (including the `6d` derived axioms). This argument still needs a line-by-line game-to-resolution presentation before it can be called a polished proof, but its combinatorial core and width accounting have survived the current checks.

- **2026-08-28 13:21 CEST — Verified slack-capture lemma.** For a red valid step define defect `delta=1-(Delta x+Delta y)`; continuity gives `delta in {0,1,2}` (forward, stay, backward), and the total defect of a complete red walk is exactly `S=M-2D+1`. For blue use `delta=1-(Delta x-Delta y)`, again totaling `S`. A sequential scan that permanently retains the endpoints of every positive-defect edge uses at most `2S+1` blocks. The historical scan telescopes, so the retained defects have total weight exactly `S`. For any interval between consecutive retained anchors, feasibility gives `time length - progress increase >= 0`; summing these quantities and the retained defect weights gives exactly `S`, hence every unretained interval has zero defect and is forced coordinate-monotone under every later completion respecting the anchors. Thus the arbitrary-slack problem reduces, with `O(S)` retained blocks, to paths made of `O(S)` monotone pieces. This yields another route to polylogarithmic width when the excess horizon `S` itself is polylogarithmic, but does not address unrestricted `M/D`.

- **2026-08-28 13:27 CEST — Slack route repaired; width `O((S+1)d)` verified.** The missing simultaneous-intersection step can be supplied by recursive spatial bisection and mod-2 intersection. Retaining all positive-defect edges partitions each curve into coordinate-monotone good intervals. At any vertical separator, each good interval crosses at most once and every bad edge is already fixed, so all crossing occurrences of the two current subpaths can be located by time binary search and retained using `O(S+1)` blocks. Split each path at these occurrences into arcs lying wholly in the two half-rectangles. The mod-2 intersection number of the two parent arcs is 1 exactly when their endpoints alternate on the parent boundary; additivity over the split implies that some red child arc and blue child arc in one half have intersection number 1, equivalently alternating endpoints on that half's boundary. Choose that pair, retain its four boundary blocks, discard the other crossing blocks, and recurse spatially. Containment remains authenticated: between consecutive separator events every fixed bad edge stays on the chosen side, and every good interval is coordinate-monotone with fixed endpoints and hence cannot make a hidden return across the separator. After at most `d` vertical bisections, the region is one column. Alternating endpoints there give overlapping one-dimensional value intervals, and ordinary time bisection forces both paths to a common vertex. At any moment the strategy stores the `O(S)` global defect anchors, `O(S)` current separator crossings, and `O(1)` search/end blocks; hence `O(S+1)` full point blocks, i.e. Boolean width `O((S+1)d)`, on top of the width-`6d` long-range derivations. This resolves the immediately preceding subclaim but is not polylogarithmic when `S` is large.

- **2026-08-28 13:43 CEST — Pure-resolution game translation audited.** Weakening is not part of the PDF's resolution rule, but it is unnecessary. Thus a finite strategy retaining at most `K` Boolean assignments gives a width-`K` pure-resolution refutation. A full-block strategy is simulated by querying its `2d` bits successively. - **2026-08-28 14:06 CEST — Verified unconditional width `O(D^2 d)`.** Sequentially query the red blocks, keeping a stack of timestamped blocks whose values are the ordinary online loop erasure of the historical red walk. The stack values always form a simple grid path from the red start to the current red value, even though consecutive representatives need not have consecutive timestamps after a pop: adjacency is a fact about their retained values, inherited from the just-queried duplicate and its successor. Its size is at most the number `D^2` of grid vertices. At the end it is a fixed simple grid path from southwest to northeast. Retain this entire stack and scan blue sequentially, retaining each blue block until its successor is queried. The historical blue answers form a continuous northwest-to-southeast walk. A simple southwest-to-northeast arc, completed by the appropriate square-boundary arc to a Jordan curve, separates those blue endpoints, so some queried blue value equals a retained red-stack value; at that moment the corresponding disjointness clause is falsified. Thus the block game uses at most `D^2+2` full blocks, and the audited pure-resolution translation gives width at most `2d(D^2+2)` (up to the initial clause width `4d`). - **2026-08-28 14:20 CEST — Hierarchical-defect compression attempt.** Interval defect is computable from its two retained endpoints and is exactly additive after querying a midpoint.
